# 📝 Notes App

A clean, minimal notes application built with pure **HTML**, **CSS**, and **JavaScript** — no frameworks, no dependencies.

---

## ✨ Features

- ➕ Create new notes instantly
- ✏️ Edit notes in place
- 🗑️ Delete notes with one click
- 💾 Persistent storage via `localStorage`
- 📱 Fully responsive design
- ⚡ Zero dependencies — runs in any browser

---

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/your-username/notes-app.git
cd notes-app
```

### Run locally

Just open `index.html` in your browser — no build step, no server required.

```bash
# Option 1: Open directly
open index.html

# Option 2: Use a local server (optional)
npx serve .
```

```
notes-app/
```

---

## 🛠️ How It Works

| Layer        | Technology          | Role                            |
|--------------|---------------------|---------------------------------|
| Structure    | HTML5               | Markup & layout                 |
| Styling      | CSS3                | Responsive design & animations  |
| Logic        | Vanilla JavaScript  | CRUD operations & state         |
| Persistence  | `localStorage`      | Notes survive page refresh      |

---

## 💡 Usage

1. Click **"+ New Note"** to create a note
2. Type your content directly in the note card
3. Click the **delete icon** (🗑️) to remove a note
4. Notes are **automatically saved** to `localStorage`
